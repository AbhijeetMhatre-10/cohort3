## 🌟 About Project

**Productivity Dashboard** is a clean and modern web application designed to help users stay organized and focused. It combines task management, daily goals, a Pomodoro timer, planner, real-time weather, live clock, and motivational quotes into a single intuitive dashboard for better daily productivity. 🚀

## 🛠️ Tech Stack

### Technology & Purpose:
- 🌐 HTML5 - Structure and layout of the application
- 🎨 CSS3 - Responsive UI, styling, animations, and themes
- ⚡ JavaScript (ES6+) - Application logic, DOM manipulation, and interactivity
- 💾 Local Storage API - Persisting tasks, goals, planner entries, and user settings
- 📍 Geolocation API - Fetching the user's current location
- 🌍 OpenStreetMap (Nominatim API) - Reverse geocoding (City, State, Country)
- 🌦️ Open-Meteo API - Real-time weather data (temperature, humidity, wind, precipitation)
- 💬 Quotable API - Displaying motivational quotes
- ⏰ Browser Timer APIs - Pomodoro countdown and live clock
