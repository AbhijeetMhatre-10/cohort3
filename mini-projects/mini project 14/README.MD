## About Project

### 💰 FinTrack Pro

A modern, browser-based **Personal Finance Tracker** built using **HTML, CSS, and Vanilla JavaScript**. FinTrack Pro helps users manage their finances with secure authentication, real-time analytics, and an intuitive dashboard—all powered by `localStorage` without any backend.

#### ✨ Features

* 🔐 User Registration & Login Authentication
* 💼 Personalized Dashboard for Each User
* 💰 Track Current Balance, Total Income & Total Expenses
* 📊 Real-Time Cash Flow Analysis with Interactive Charts
* 📝 Add, Edit & Delete Transactions (CRUD)
* 🔍 Search, Filter & Sort Transactions
* 🌍 Multi-Currency Support (INR, USD, EUR, GBP)
* 🌙 Dark Mode with Persistent Preferences
* ♻️ Reset Financial Data (User-Specific)
* 📱 Fully Responsive & Modern FinTech UI
* 💾 Data Persistence using `localStorage`
* ⚡ Instant UI Updates without Page Refresh
* 🧩 Modular Code Structure with Separate HTML, CSS & JavaScript Files

#### 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* Chart.js
* localStorage
